# ADR-001: Размещение критериев оценки (автотестов) в Сервисе проверки

## Status

Proposed

## Context

Критерии оценки (автотесты) — это код, который должен где-то исполняться. LMS университета работает на мэйнфрейме и не предназначена для запуска кода студентов. Требуется определить, где будут храниться и исполняться критерии, и как преподаватель будет с ними работать.

## Decision

Мы будем хранить и исполнять критерии оценки (автотесты) в Сервисе проверки. Преподаватель будет задавать их напрямую в интерфейсе Сервиса. LMS будет получать только ссылку на задание и его статус.

## Consequences

Положительные:

- Критерии находятся там, где исполняются — снижается сложность интеграции.
- Преподаватель работает в среде, предназначенной для кода.
- LMS не нужно дорабатывать для хранения кода тестов.
- Преподаватель устанавливает и дедлайны и критерии в одном месте.

Отрицательные:

- Необходима синхронизация с LMS для передачи данных об дедлайнах из Сервиса провери.
- Появляется риск рассинхронизации: задание в LMS может быть, а критериев в Сервисе ещё нет.
- Требуется разработать механизм сохранения истории в LMS.
