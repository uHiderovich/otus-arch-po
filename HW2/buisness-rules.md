# Бизнес-правила

1. Студент может отправлять неограниченное количество попыток решения до наступления дедлайна.
2. После наступления дедлайна новые попытки решения не принимаются.
3. После наступления дедлайна критерии проверки задания не изменяются.
4. Преподаватель может вручную скорректировать выставленную оценку.
5. Решение не может получить положительный результат, если не выполнены обязательные критерии проверки.
6. Каждая отправка решения создаёт отдельную попытку и не заменяет историю предыдущих попыток.
7. Для каждой попытки фиксируются результат проверки и полученная оценка.
8. Результаты и история попыток должны сохраняться для последующего аудита.
9. Результат проверки должен быть передан в LMS.
