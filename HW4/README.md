# Домашнее задание

Системное проектирование

## Цель:

спроектировать контейнерную структуру приложения, слой данных и схему развертывания для формализации системной архитектуры решения.

## Описание/Пошаговая инструкция выполнения домашнего задания:

Для выбранного кейса опишите слой решения:

1. Диаграмма контейнеров приложения на основе выбранной модели функциональной декомпозиции
2. Декомпозиция слоя данных: какие данные в каких БД хранятся
3. Деплоймент-диаграмма

## Аутентификация и авторизация

- **Аутентификация** студентов и преподавателей выполняется средствами LMS. Предполагается, что LMS предоставляет API для аутентификации и получения сведений о пользователе, включая его уникальный идентификатор и роли.

- Система автоматической проверки не хранит пароли пользователей.

- Проверка прав доступа к заданиям, попыткам и результатам выполняется в Backend API на основании роли пользователя и его полномочий.

- Конкретный протокол интеграции с LMS требует уточнения. Предпочтительно использование стандартного механизма единого входа.
